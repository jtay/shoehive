`create-shoehive` (Phase 7 of RFC 0001): `npm create shoehive@latest my-game` scaffolds a playable game with a game server, a React app, tests and devtools. Templates `tic-tac-toe` (default) and `blank`; flags `--template`, `--no-install`, `--no-git`, `--package-manager`, `--shoehive` and `--yes`. It versions with `shoehive` and pins the generated project to the release it ships with.
