---
'shoehive': minor
---

Network security review fixes (docs/security/review-1.0-network.md). A `view()` that throws no longer stops the process: that viewer misses the update (logged) and the action still succeeds. A connection whose send buffer passes `limits.maxBufferedBytes` (default 8 MiB) is dropped, and lobby patches now respect backpressure like table patches. `table.create` from clients is refused with `FORBIDDEN` past `limits.maxTablesPerPlayer` (default 10 open tables) or `limits.maxTables` (default 10 000). Guest session records are deleted when the session expires, and `player.rename` returns a fresh resume token that `shoehive/client` stores. A second `hello` on one connection is refused, `act.input` and `table.create.options` must have finite numbers and at most 32 levels of nesting, and display names may not contain line separators or bidirectional overrides. The server warns when an `auth` hook is set without `origins`. The client ignores malformed server messages, resyncs on a patch that does not apply, and waits 30 s after close code 4429; `applyPatch` rejects operations and paths outside RFC 6902 add, remove and replace.
