In five minutes you will have a two-player tic-tac-toe game running on your machine, and you
will have changed one of its rules. You need [Node.js](https://nodejs.org/) 22 or newer.

## Create a project

The scaffolder copies the tic-tac-toe template into `my-game/` and installs its dependencies.

<TabItem label="npm">


## Play it

Run the commands the scaffolder prints at the end:

```sh
cd my-game
npm run dev
```

This runs the web app with hot reload and the game server, which restarts whenever you change
the game.

Open http://localhost:5173 in two browser windows, and make one of them private, so that each
window is a different guest player. Create a table in one window and take a seat, then take
the other seat in the second window. Play.

## What is in the project

| File                | What it is                                                    |
| ------------------- | ------------------------------------------------------------- |
| `src/game.ts`       | The rules: state, actions, turns and when the game ends       |
| `test/game.test.ts` | Tests for the rules, run without a server or a browser        |
| `src/server.ts`     | The game server: the WebSocket endpoint and the built app     |
| `web/App.tsx`       | The React app: lobby, seats and board, using `shoehive/react` |

The whole game is one `defineGame` call in `src/game.ts`. It has a starting state (`setup`),
a turn order, and one action, `place`.

`reject()` stops the action. Nothing it changed is kept, and the player gets the error code.
Save the file: the game server restarts by itself. Start a new table and try the centre.

## Look inside

When the game server starts, it prints a devtools link. Open it to see every table's state,
what each seat's view contains, and the action log, including your rejected centre move.

## Scripts

| Command             | What it does                                                      |
| ------------------- | ----------------------------------------------------------------- |
| `npm run dev`       | Web app with hot reload, plus the game server in watch mode       |
| `npm test`          | Runs the tests with Vitest                                        |
| `npm run typecheck` | Type-checks everything                                            |
| `npm run build`     | Builds the web app for production                                 |
| `npm start`         | Serves the built app and the game server on http://localhost:3000 |
